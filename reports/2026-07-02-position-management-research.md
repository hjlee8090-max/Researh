## 2. 왜 매수 쪽이 마비됐나 — 숫자로 본 병목 3개

### 병목 A. 히트(위험예산) 잠금 — 가장 크고 시급함

7/2 09:20 `state/allocation.json` 실측:

```
주식 비중 60.0% (목표 80~95%) → recommendation: deploy 1,372,090원
포트폴리오 히트: 예산 449,048원(9%) < 현재 open_risk 524,158원(10.51%) → 잔여 0원
vacant_slots: 0  →  결론: 신규·추가매수 전면 차단 (7/1, 7/2 연속)
```

원인은 산술 모순이다. 히트 예산 9%(strong_bull)는 정책 원문상 **"손절폭 ~10%" 가정으로 설계**됐다(`risk.max_single_trade_risk_pct_of_equity_by_tier.purpose`: "strong_bull 3.5%×equity÷손절10%≈종목당 ~30%"). 그런데 노이즈 손절을 막으려고 손절을 -2×ATR로 넓힌 결과(v2.11), **현 보유 6종목의 실제 손절폭은 6.2%~23.1%, 평가액 가중평균 ≈ 15.7%**다:

| 종목 | 손절폭(진입가 대비) | open_risk (7/2) | 히트 예산 점유율 |
|---|---|---|---|
| LIG넥스원 | -21.0% | 186,857원 | **41.6%** |
| 한미반도체 | -23.1% | 94,714원 | 21.1% |
| LS ELECTRIC | -6.2% | 94,572원 | 21.1% |
| 삼성SDI | -16.8% | 73,500원 | 16.4% |
| 신한지주 | -11.2% | 48,715원 | 10.8% |
| 하나금융지주 | -11.3% | 25,800원 | 5.7% |

목표 중앙(87.5% 투입)을 이 손절 구조로 달성하려면 필요 히트 ≈ 0.875 × 15.7% ≈ **13.7%** — 예산 9%로는 **수학적으로 도달 불가**하다. 6% 시절 "3종목 60%에서 막힘"을 고치려 9%로 올렸지만(v2.5), 스톱을 넓히면서 같은 벽이 60% 지점에 다시 생겼다. **백테스트로 검증한 전략(항시투자 Top6, +302.9%)을 백테스트에 존재하지 않던 오버레이(히트 예산)가 막는 구조** — web_verify 차단이 만든 구 '현금 마비'(v2.19에서 해소)와 동종의 결함이다.

여기에 **리스크 인플레이션**이 가세한다. open_risk = 주수 × (현재가 − 손절가)인데, 손절선은 목표진행 70%(트레일링 활성화) 전까지 진입가−2×ATR에 고정이라 **주가가 오를수록 히트가 부푼다**. LIG넥스원은 진입 시 155,442원이던 리스크가 +4.3% 상승으로 186,857원까지 커져 단일거래 상한(3.5%=174,630원)마저 사후 초과했다 — 그런데 사후 초과에 반응하는 룰이 없다.

### 병목 B. 슬롯 모순 — 재량 진입 경로 사문화

`position_sizing.max_positions = 5` vs 현 보유 6종목 vs momentum `top_n = 6`. `compute_allocation.py:195-198`이 vacant_slots = max(0, 5−6) = **0을 영구 산출** → 09시 §2-C(deploy 시 복수 종목 진입 의무) 경로가 바스켓 만석인 동안 구조적으로 죽는다. 정합 실수로 보인다(6/30 top_n 10→6 축소 때 max_positions 미동기화).

### 병목 C. SCALE_IN 삼중 게이트 + 뉴스 배선 부재

`scale_in_rule`: "thesis 강화 **AND** 신뢰도 high **AND** 현금 비중이 목표보다 높을 때만". 세 조건이 동시에 참인 순간은 드물고, 참이어도 병목 A가 최종 차단한다. trade_log에는 차단 기록만 4건(6/10 FOMC D-4, 6/16 "FOMC 후 예정", 6/18·22 post_close 금지·목표 근접 보류) — **의지는 있었으나 실행이 0건**. 한편 뉴스 피드(자동 수집·12유형 분류·전이계수까지 갖춘 파이프라인)는 목표가 추정(참고 레이어)에만 흘러가고, "이 뉴스가 나오면 증량을 평가하라/트레일을 조이라"는 **행동 배선이 없다**.

## 4. 돈을 버는 운영의 3원칙 — 현 시스템과의 충돌 지점

1. **시장에 있어라 (Exposure).** 레포 자체 백테스트(30종목×592거래일): 항시투자 Top6~10 동일가중·월간 리밸 = **+302.9%, Sharpe 2.18, MDD -21.1%** vs KOSPI +207.5%/2.13/-19.9%. 전략의 알파는 종목 선택보다 "현금으로 새지 않는 것"에서 나왔다. → **충돌: 병목 A·B가 60% 투입에서 강제 정지.**
2. **승자에게 물을 주고, 패자에게서 물을 빼라 (Asymmetry).** 지금은 반대로 작동할 위험이 있다: LS ELECTRIC +14.3%는 9.6% 비중 그대로(증량 불가), 한미반도체 -14.5%는 손절 -23.1%까지 풀비중 유지. 모멘텀 신호(7/2)는 이미 답을 내놨다 — 증량 대상 LS 2→4주·삼성SDI 1→2주, 회전아웃 후보 한미반도체(score 9.3), 신규 삼성전자·삼성물산. 그러나 월간 리밸(21거래일, D+19)까지 대기가 기본이고 SCALE_IN은 마비 상태. → **충돌: 승자 증량 경로 0건, 패자 회수는 시간손절(목요일 룰)이 있으나 min_hold 5일과 충돌 소지.**
3. **노이즈에 팔리지 마라 (Noise immunity).** ATR 적응 임계·2단 트레일·orange 원인 분기는 이미 잘 설계됐고 유지해야 한다. → **단, 스톱을 넓혔으면 히트 예산을 같이 재보정했어야 했다. 넓은 스톱의 비용을 예산이 아니라 '배치 차단'으로 지불하는 게 현 구조다.**

## 5. 개선안 (우선순위·정책 패치 스니펫·검증 방법)

### P1. 본전 래칫 스톱 — 히트 재활용 (최우선, 즉시 후보)

이익 진행 시 손절선을 계단식으로 끌어올린다. **종가 기준 판정**(기존 트레일링과 동일)이라 장중 노이즈 면역이고, 6/23 보호손절(+25,369 확정)이 이미 유효성을 실증했다.

```jsonc
// policy.risk.breakeven_ratchet (신설)
{
  "enabled": true,
  "basis": "close",                       // 종가 판정 — 노이즈 체결 방지
  "steps": [
    {"when_gain_atr": 1.0, "stop_to": "entry_plus_costs"},   // +1.0×ATR 도달 → 본전+거래비용
    {"when_gain_atr": 2.0, "stop_to": "entry_plus_0.5_atr"}  // +2.0×ATR 도달 → 본전+0.5ATR
  ],
  "note": "트레일링(목표진행 70%~)의 사각지대인 '초기 이익 구간'을 메운다. 스톱은 올리기만 한다(래칫)."
}
```

- **효과(오늘 실측)**: LS ELECTRIC(+14.3%, ATR 기준 통과)이 즉시 해당 — 스톱 216,214→230,495원으로 open_risk 28,562원 해방. LIG넥스원은 +1×ATR(816,306원) 도달 시 **155,442원(예산의 35%) 해방** → 추가매수 실탄이 룰 안에서 생긴다.
- **리스크**: 본전 스톱이 노이즈에 걸릴 수 있다(KB금융 give-back 교훈). ATR 게이트(+1×ATR 이후에만)와 종가 기준이 1차 완충. **2주 그림자 채점**(체결 없이 inference_log에 가상 기록→ score_inferences로 t1/t5 기회비용 비교) 후 본가동 권장.

### P2. 히트 예산 재보정 — 스톱 폭과 정합 (구조 교정)

```jsonc
// policy.risk.portfolio_heat_budget_by_tier 수정안
{
  "strong_bull": 14.0,   // 현 9.0 — 근거: 목표투입 87.5% × 가중평균 스톱폭 15.7% ≈ 13.7%
  "bull": 10.0,          // 현 7.5 추정 동일 논리로 재산출
  "dynamic_formula_option": "budget = clamp(target_midpoint_pct × basket_weighted_stop_width, 9, 16)",
  "pairing": "P1 래칫과 반드시 병행 — 래칫 없이 예산만 키우면 하방 노출 순증"
}
```

- **근거**: §2 병목 A의 산술. 예산 상향은 "위험 확대"가 아니라 **이미 백테스트로 수용한 위험(MDD -21%)을 오버레이가 이중 차단하던 것을 해제**하는 것이다. 주간 -5% 계좌 한도·종목별 -2×ATR·검은화요일式 if-then 보호손절은 그대로 유지된다.
- **검증**: `backtest_strategy.py`에 히트 오버레이를 추가 구현해 9% vs 14% vs 무제한 3안의 총수익/MDD를 재실행 — "파라미터 변경은 백테스트 근거 필수" 원칙 준수.

### P3. max_positions 5→6 — 슬롯 정합 (즉시, 무위험)

```jsonc
// policy.position_sizing
{ "max_positions": 6 }   // momentum_strategy.config.top_n=6과 동기화. vacant_slots 영구 0 해소
```

### P4. 승자 증량 룰 — SCALE_IN을 발화 가능하게 (P1·P2 통과 후)

물타기는 계속 금지하고, **불타기(이익 중 증량)만** 명시 허용한다:

```jsonc
// policy.risk.dynamic_exit_model.scale_in_rule 교체안
{
  "direction": "winners_only",            // 평가손 상태 추가매수(물타기) 금지 명문화
  "trigger": "보유 수익 ≥ +1.5×ATR (종가) AND momentum score ≥ min_score(30) AND thesis intact",
  "size": "min(초기 수량의 50%, 히트 잔여, 종목 35% 캡)",
  "stop_after_add": "합산 평단 기준 본전 이상 (래칫 유지 — 증량이 스톱을 되내리지 못함)",
  "frequency": "종목당 최대 2회, 간격 ≥ 3거래일",
  "gates_unchanged": "pre_trade_gate·신뢰도·촉매 D-1 blackout·min_hold 등 기존 게이트 전부 유지"
}
```

- 현행 삼중 게이트 중 "현금>목표" 조건은 삭제(deploy 국면과 모순 — 현금이 목표 초과일 때만 증량 가능하면 항시투자와 양립 불가), "thesis 강화"는 "intact + 모멘텀 점수"로 객관화.
- **효과 예시(오늘)**: 모멘텀 신호의 LS 2→4주 증량이 P1(래칫)으로 해방된 히트 안에서 합법적으로 집행 가능해진다.

### P5. 뉴스 양방향 액션 맵 — '참고 숫자'를 '트리거'로 (저위험·고가치)

기존 뉴스 파이프라인(수집·분류·신뢰도 할인)은 그대로 두고, 분류 결과에 **행동 의무**를 배선한다:

```jsonc
// policy.news_action_map (신설) — 보유 종목 한정
{
  "negative_structural": {   // 규제·소송·회계·공급망 단절 등 news_impact 음(-) 구조 유형
    "action": "green이어도 즉시 thesis 재판정 + 타이트 트레일(고점 -1.0×ATR) 전환 검토를 다음 슬롯 의무화",
    "existing_hook": "orange_action (a)분기·thesis hard 청산과 접속 — 신규 배선은 '경보 전 선제 검토'"
  },
  "positive_high_impact": {  // 수주·계약, 실적 서프라이즈 등 impact ≥ +3%·confidence ≥ 0.6
    "action": "다음 live 슬롯에서 P4 증량 평가를 의무 기록 (체결은 전 게이트 통과 시에만)",
    "note": "post_surge_cooldown(급등 당일 추격 금지)과 병존 — 급등 전 포착분만 유효"
  }
}
```

- 이미 있는 조각들(구조 악재 키워드 스캔=진입측, sharp_decline=축소측)의 **보유·매수측 대칭 완성**이다. 판단은 여전히 routine이 하고, 맵은 "검토를 잊지 않게" 강제할 뿐이라 과최적화 위험이 낮다.

### P6. breadth 서킷브레이커 '장전 조건' 명문화 (테일 리스크)

현재 `regime_circuit_breaker.enabled=false`이고 켜는 건 사람 재량이다 — 폭락 중 재량 판단은 늦는다(검은화요일 -9.99% 실증). 상시 ON은 강세장 비용이 크므로(backtest_bear: +272→+216), **켜는 조건 자체를 사전 커밋**한다:

```jsonc
// policy.momentum_strategy.regime_circuit_breaker.auto_arm (신설)
{ "arm_when": "breadth(유니버스 MA200 상회 비율) < 0.45 가 2거래일 연속", 
  "action": "09시 routine이 enabled=true 전환을 의무 검토·기록(카톡 통지)", 
  "disarm": "breadth > 0.55 5거래일 연속" }
```

- 지수는 현재 MA200 대비 +48% — 멜트업 구간이라 브레이커 비용이 아깝지만, 바로 그래서 '장전 룰'이 필요하다. KOSPI +25% 구간에서 하루 -10%가 이미 나왔다.

### P7. 시간손절 vs min_hold 충돌 해소 (소규모 정리)

`risk.time_stop`(목요일 15시, 주간 기여 30% 미만 축소·교체)과 `horizon.min_hold_days=5`가 W27처럼 화·수 진입 주에 충돌한다(오늘이 그 목요일 — 한미반도체 score 9.3·-14.5%가 대상인데 D+2). **우선순위 명문화**: "min_hold는 이익·중립 종목의 회전 마찰 방지용 — 손실 + 모멘텀 소멸(score<10) 종목에는 time_stop·회전아웃이 우선한다."

## 6. 반론과 한계 (정직 항목)

- **래칫·증량은 상승장 편향 룰이다.** 횡보·급반락 장에서는 본전 스톱 체결이 늘어 잔손실이 쌓일 수 있다. → P1 그림자 채점 2주 + rule_attribution에 `RATCHET_STOP`/`SCALE_IN` 룰 라벨을 추가해 실현손익·forgone을 기존 매도 룰과 동일 기준으로 채점하라(채점 인프라는 이미 있다).
- **히트 예산 상향은 낙폭을 키운다.** 백테스트 MDD -21%를 "수용한 위험"으로 재확인하는 결정이며, 이는 시뮬레이션이라 가능한 선택이다. 실전 전환 시 재검토 대상 1순위.
- **시세가 웹 근사값**이라 래칫·증량의 체결가 정밀도는 낮다 — 다만 이 한계는 기존 매도 룰도 동일하게 지므로 비교 채점은 유효하다.
- **이 리포트의 숫자는 7/2 09:20 스냅샷 기준**이다. 히트·open_risk는 가격과 함께 매 슬롯 변한다.
