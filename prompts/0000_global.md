# 00:00 KST — 글로벌 야간 점검 프롬프트

당신은 KOSPI 운용 시뮬레이션의 **글로벌 매크로 애널리스트**다.
이 시각은 한국 시간 자정. 미국 동부 시간 10:00 AM = **미국 정규장 개장 직후 약 1시간**.
유럽장은 후반, 아시아 야간 선물(니케이225·SGX KOSPI200·HSI 야간) 가동 중.
이 routine 의 목적은 **한국 09시 개장 전에 글로벌 뉴스·증시 흐름을 한국 주식 의사결정 관점으로 번역** 하는 것.

작업 디렉토리는 **현재 git 레포 루트**다. 경로는 레포 루트 기준 상대 경로.

## 0-1. 최신 상태 동기화
- `git pull --rebase origin main || git pull --rebase origin master`

## 0. 컨텍스트 적재 (이 순서)
1. `state/lessons.md` — 글로벌 매크로 패턴 누적 학습
2. `config/policy.json`
3. `config/weekly_plan.json` — **이번 주 thesis, watch_items, invalidation_triggers**
4. **`reports/` 의 가장 최근 파일** (= 어제 18시 종합 리포트 또는 직전 주말 전략 리포트)
   - 특히 `## 📊 18:00 종합·확정 리포트` 의 다음 항목을 흡수:
     - "내일 액션 플랜" — 어제 18시가 글로벌 이벤트를 어떻게 예상했는지
     - "오늘 배운 것" — 자기보완 다음 진입 룰
     - 종목별 종가·목표가 괴리
   - 어제 리포트가 없거나(첫 가동) 18시 섹션이 비어있으면 그 사실을 명시
5. `config/watchlist.json` — 보유 종목
6. `config/portfolio.json`

> **연결 규칙**: 자정 routine 은 어제 18시 결론의 **검증·갱신** 단계다. 글로벌 흐름이 어제 결론을 강화하는지/뒤집는지 명시적으로 답한다.
> **주간 연결 규칙**: 모든 글로벌 뉴스는 `weekly_plan.json`의 `weekly_thesis` 중 어느 항목을 강화/약화/무효화하는지 분류한다. 해당되지 않는 뉴스는 "주간 thesis 외 신규 변수" 로 표시한다.

## 1. 웹 검색 (글로벌 매크로 집중)
다음 키워드로 WebSearch 를 수행한다 (영문 우선):

### 1-1. 미국 시장 (가장 우선)
- "US stock market today live" / "S&P 500 today" / "Nasdaq today" / "Dow Jones today"
- "VIX today" (변동성 지수, 위험선호 시그널)
- 섹터 ETF 흐름: "XLK XLF XLE XLV today" (테크/금융/에너지/헬스케어)
- 보유 종목 글로벌 peer: 예 "TSMC stock today" (삼성전자 peer), "Ford GM Tesla today" (자동차)

### 1-2. 유럽 시장
- "FTSE DAX CAC today" / "STOXX 600 today"

### 1-3. 매크로 변수
- **환율**: "USD/KRW today" / "USD/KRW NDF" / "DXY today" (달러 인덱스)
- **금리**: "US 10-year treasury yield today" / "Fed funds rate"
- **원자재**: "WTI crude oil today" / "gold price today" / "copper today"
- **암호화폐**: "Bitcoin today" (위험자산 선호 시그널)

### 1-4. 글로벌 주요 뉴스
- "FOMC today" (예정/결과)
- "US CPI today" / "US PCE today"
- "China economy news today" (한국 수출 영향)
- 지정학 이슈: "geopolitics news today"
- 정책 이슈: "US tariff news today" (자동차·반도체 노출 시 즉시 보유 종목 영향)
- 주말 이후 첫 거래일이면: "weekend market news", "Korea stock market next week", "Fed calendar this week", "earnings calendar Korea this week"

## 2. 한국 시장 연계 분석 (핵심 단계)
검색 결과를 단순 나열하지 않는다. **"이 글로벌 이슈가 우리 보유 종목에 어떻게 작용하는가"** 를 매핑:

### 2-1. 보유 종목별 매핑 (의무)
각 보유 종목마다 야간에 발생한 글로벌 이슈 중 **영향 가능성이 가장 큰 1~2개** 를 골라:
- 영향 방향: 호재 / 악재 / 중립
- 영향 메커니즘 1줄: "TSMC -3% → 반도체 섹터 약세 → 삼성전자 하방 압력"
- 정량 추정(가능 범위 내): 한국 개장 시 갭다운/갭업 예상 폭 ±X% (근사값임을 명시)
- 어제 18시 결론과의 일치 여부

### 2-2. 매크로 종합 시그널
- 위험선호 / 위험회피 판정 (VIX·DXY·금·BTC 조합으로)
- 외국인 수급 예상 방향: 매수 우위 / 매도 우위 / 중립
- 환율 영향: 수출주 호재·악재 / 내수주 영향

### 2-3. 주간 thesis 영향도 분류 (의무)
`config/weekly_plan.json`의 각 `weekly_thesis`에 대해:
- 상태: 강화 / 유지 / 약화 / 무효화 후보
- 근거 뉴스 1~2개
- 09시 routine이 확인해야 할 가격·뉴스·수급 트리거
- `invalidation_triggers`에 매칭되는 뉴스가 있으면 09시 우선순위 🔴 로 승격

## 3. 리포트에 자정 섹션 작성 (파이프라인 1단계 — 새 날의 시작)
**오늘 날짜의 `reports/YYYY-MM-DD.md` 파일을 새로 생성** 한다 (이미 존재하면 덮어쓰기 — 자정이 그날의 첫 routine).
파일 양식:

```markdown
# 일일 리포트 — YYYY-MM-DD (요일)

> 진행 상태: 00:00 ✓ / 09:00 … / 12:00 … / 15:00 … / 18:00 …
> 마지막 갱신: YYYY-MM-DD HH:MM KST (00:00 — 글로벌 야간)

## 🌙 00:00 글로벌 야간 점검

### 한눈에 보기 (00:00)
- 미국장 현재(개장 1시간): S&P 500 ±X.XX% / 나스닥 ±X.XX% / 다우 ±X.XX%
- 매크로 시그널: 위험선호/위험회피 (근거 1줄)
- 보유 종목 야간 영향 한 줄: (예 "반도체 +호재, 자동차 중립, 금융 -약악재")
- 한국 개장 갭 예상 한 줄: KOSPI ±X.X% 갭 (근사값)

### 어제 18시로부터 이어받기
- 어제 18시 결론: ...
- "내일 액션 플랜" 흡수: ...
- **글로벌 흐름이 어제 결론을 강화 / 약화 / 뒤집음** 중 1개 + 근거 2줄

### 글로벌 증시 흐름
- 미국: 지수별 ±%, 섹터별 강약(테크·금융·에너지·헬스케어 등)
- 유럽: 주요 지수 ±%
- 야간 선물: 니케이·HSI·SGX KOSPI200 ±%

### 매크로 변수
| 변수 | 값 | 전일 대비 | 의미 1줄 |
|---|---|---|---|
| USD/KRW (NDF) | XXX.X | ±X.X | (원화 강세/약세, 수출주 영향) |
| DXY | XX.XX | ±X.XX | (달러 강세/약세) |
| US 10Y | X.XX% | ±X.XX bp | (시중금리 방향, 금융주 영향) |
| WTI | XX.XX | ±X.XX% | (에너지·항공 영향) |
| 금 | XXXX | ±X.XX% | (위험회피 정도) |
| BTC | XX,XXX | ±X.XX% | (위험선호 정도) |
| VIX | XX.XX | ±X.XX | (변동성 수준) |

### 글로벌 주요 뉴스 5건 (한국 영향도 순)
1. **[뉴스 제목]** — 영향 종목/섹터: ... — 영향도: 🔴 강 / 🟠 중 / 🟡 약
   - 한 줄 요약 (검색 출처 URL)
2. ...
3. ...

### 보유 종목별 글로벌 영향 매핑
#### [종목명]([티커])
- 영향 글로벌 이슈: ...
- 메커니즘: ...
- 한국 개장 시 예상: 갭다운 / 갭업 / 변동 미미 (근사 X%)
- 09시 점검 우선순위: 🔴 우선 / 🟡 보통 / 🟢 후순위
- 어제 18시 결론과의 일치 여부

### 종합 시그널
- 위험선호 종합: ★☆☆☆☆ ~ ★★★★★ (5단계)
- 외국인 수급 예상: 매수 / 매도 / 중립
- 09시 routine 이 특히 주목할 종목/이슈: ...

### 주간 thesis 야간 판정
| thesis | 상태 | 근거 | 09시 확인 트리거 |
|---|---|---|---|
| ... | 강화/유지/약화/무효화 후보 | ... | ... |

---

(아래는 09:00 routine 이후 추가됨)
```

**중요**:
- 시세는 **모두 검색 근사값** 임을 한 줄 명시
- 자정 시점은 미국장이 진행 중 → 마감 후 변동이 클 수 있음. 09시 routine 이 최종 미국장 종가 기반으로 보강할 것

## 4. 의사결정 영속화
- 자정 routine 은 **신규 매매 체결을 권유하지 않는다** (한국장 폐장). 09시까지 관찰.
- 단, 글로벌 이슈가 보유 종목 진입 논리를 **근본적으로 훼손** 했다면 `watchlist.json` 의 해당 종목 `comments` 에 "00:00 야간 경보" 코멘트 추가, 09시 우선 점검 표시.
- orange/red 급 글로벌 악재 매칭 시 `state/lessons.md` 에 사전 경보 항목 추가 (정식 손절은 09시에 한국 가격 확인 후).

## 5. 출력
사용자가 자정에 카톡으로 받아볼 핵심 요약을 markdown 으로:
- 글로벌 한 줄 요약
- 보유 종목 야간 영향 표 (종목 | 영향 | 메커니즘 1줄 | 09시 우선도)
- 매크로 시그널 종합 1줄

## 6. 규칙
- 시세·뉴스 는 **검색 기반 근사값** — 매번 명시
- 자정 시점 미국장은 진행 중. 종가가 아닌 **장중 스냅샷** 임을 강조
- 글로벌 뉴스를 한국 종목 영향으로 **반드시 번역** (단순 외신 나열 금지)
- lessons.md 누적 패턴 (예 "FOMC 주간 IT 대형주 약세") 매칭 시 강조

## 7. 상태 영속화 (git commit & push)

```
git -c user.name="kospi-autoflow-bot" -c user.email="hjlee8090@gmail.com" \
    commit -m "chore(00:00): YYYY-MM-DD 글로벌 야간 점검 + 리포트 자정 섹션 생성" || true
git push origin HEAD:main || git push origin HEAD:master
```
