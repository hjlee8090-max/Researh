# 자기보완 학습 노트 (lessons.md)

> 18시 점검에서 **목표가 vs 실제 종가 오차 ±5% 초과**가 발생할 때, 그리고 12·15시 점검에서 **orange/red 단계 진입 또는 손절 체결**이 발생할 때마다 사유를 누적한다.
> 모든 추천·점검 프롬프트는 동작 직전 이 파일을 먼저 읽고 동일 실수를 피한다.

## 분류 체계
- **매크로**: 환율, 금리, KOSPI 지수, 미국 시장 영향
- **섹터**: 업종 단위 이슈 (반도체 사이클, 2차전지 수요, 정책 등)
- **개별**: 실적·공시·임원 변동·소송 등 종목 고유 이슈
- **가정오류**: 애널리스트의 시나리오·밸류에이션·심리 가정 자체가 틀림

## 누적 패턴 카운터
_(최종 갱신: 2026-05-26 18시)_
- 매크로 오차: 1건
- 섹터 오차: 2건 (기아 5/20, KB금융 5/26)
- 개별 오차: 0건
- 가정오류: 1건
- **루틴 오차(속보 미포착)**: 1건 — 자정 routine 22:30 속보 미포착으로 갭 예측 방향 오류
- **루틴 오차(갭다운 폭 과소 추정)**: 1건 — KOSPI 역대 최대 급등 다음날 갭다운 예측 -1~-2.5% vs 실제 -4.21%
- **루틴 오차(데이터 차단 연속)**: 1건 — stooq·Yahoo HTTP 403 2026-05-22~05-26 4거래일 연속, 스냅샷으로 회복
- 동일 섹터 반복 손실: {자동차: 1}
- 구조적 악재(관세/규제) 노출 손실: 1건

> **18시 점검 메모 (2026-05-20)**: 삼성전자·KB금융 종가 진입가 대비 각각 -0.94% / -0.72% — 허용오차 ±5% 이내. 신규 lessons 항목 없음.
> 단, 삼성전자 노사 협상 결렬(5/20 중노위 발표) → **5/21 총파업 예고** 신규 발생. 개별 리스크 (파업·생산 차질·노동비용) 로 분류 예정.

- 목표가: 168,400원 / 실제 종가: 157,300원 (괴리 -6.59%, 신뢰도: 높음)

- 분류 신뢰도: 높음 (시장스냅샷 고신뢰 데이터 기반)

- 사유 요약: KOSPI 역대 최대 상승(5/21 +8.42%, 7,815.59) 다음날 차익실현 주도 갭다운(-4.21%, 시가 ~7,486). 장중 전강 회복(15시 ~7,810~7,820)에도 KB금융 종가는 전일 추정값(162,000원) 대비 약 -1.54% 하락하여 목표가 대비 괴리가 ±5% 허용치를 초과. KB금융 개별 thesis(밸류업 자사주 1.2조 소각·고환율 NIM 방어)는 변화 없음 — 전적으로 시장 갭다운에 의한 단기 목표 도달 지연.

- 분류 신뢰도: 보통 (시장 구조적 패턴은 높음, 종가 데이터 자체 신뢰도 낮음)
