# 자기보완 학습 노트 (lessons.md)

> 18시 점검에서 **목표가 vs 실제 종가 오차 ±5% 초과**가 발생할 때, 그리고 12·15시 점검에서 **orange/red 단계 진입 또는 손절 체결**이 발생할 때마다 사유를 누적한다.
> 모든 추천·점검 프롬프트는 동작 직전 이 파일을 먼저 읽고 동일 실수를 피한다.

## 분류 체계
- **매크로**: 환율, 금리, KOSPI 지수, 미국 시장 영향
- **섹터**: 업종 단위 이슈 (반도체 사이클, 2차전지 수요, 정책 등)
- **개별**: 실적·공시·임원 변동·소송 등 종목 고유 이슈
- **가정오류**: 애널리스트의 시나리오·밸류에이션·심리 가정 자체가 틀림

## 누적 패턴 카운터
_(최종 갱신: 2026-05-21 09시)_
- 매크로 오차: 0건
- 섹터 오차: 1건
- 개별 오차: 0건
- 가정오류: 1건
- **루틴 오차(속보 미포착)**: 1건 — 자정 routine 22:30 속보 미포착으로 갭 예측 방향 오류
- 동일 섹터 반복 손실: {자동차: 1}
- 구조적 악재(관세/규제) 노출 손실: 1건

> **18시 점검 메모 (2026-05-20)**: 삼성전자·KB금융 종가 진입가 대비 각각 -0.94% / -0.72% — 허용오차 ±5% 이내. 신규 lessons 항목 없음.
> 단, 삼성전자 노사 협상 결렬(5/20 중노위 발표) → **5/21 총파업 예고** 신규 발생. 개별 리스크 (파업·생산 차질·노동비용) 로 분류 예정.
> → 5/21 장중 -5%(yellow) 도달 시 즉시 lessons 추가 의무 (policy §lessons_logging.log_immediately_on_tier_change_to_orange_or_red)

### 2026-05-20 12:00 / 기아(000270) — RED (손절 체결)
- 진입가: 181,400원 / 12시 현재가 약 158,000원 (변동률 약 -12.9%)
- 원인 분류: 섹터 + 가정오류
- 원인 요약:
  - **관세 7,550억(분기 매출의 2.56%, 연환산 ~3조)** 부담이 진입 시점에 bear_case로 명시됐음에도 conviction 4·풀비중 25% 매수.
  - 5/12 -3.84%, 5/15 -5.17% 누적 하락 추세였음. 진입 전 5거래일 추세 확인 부재.
  - 한국투자증권 220,000 vs 보수 165,000원의 목표가 컨센서스 분열을 진입 결정에 반영 못함.
  - 외국인 순매도 + 미국 EV 보조금 폐지로 인한 2030 EV 판매목표 20% 하향 발표 직후의 약세 사이클.
- 12시 점검은 단순 가격 비교만 수행. "왜 빠지는가" 분석 부재 → 단계 경보·원인분석 부재 → 손절가(-10%)를 -2.9%p 더 빠진 후 체결.
- **다음 진입 시 반영할 룰**:
  1. 구조적 악재 키워드(관세/규제/보조금폐지/제재/소송) 노출 종목은 conviction 4여도 **초기 비중 15%로 강제 축소** (policy.entry_filters)
  2. 진입 직전 **최근 5거래일 누적 수익률 검색·기록 의무**. 누적 -7% 이하면 진입 보류 (entry_filter)
  3. 장중 점검은 **단계 경보(yellow -5%/orange -7%/red -10%)** + 단계 변화 시 **원인 3가지 검색·기록 의무** (1200_midday §2·§3)
  4. orange/red 진입 시 lessons.md **즉시 기록** (18시까지 미루지 않음)
  5. 한 종목 yellow 이상이면 **함정패턴 cross-check** — 동일 섹터·매크로 보유종목 영향 즉시 확인
- 분류 신뢰도: 높음
