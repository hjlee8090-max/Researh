# 수익형 전략 엔진 — 듀얼모멘텀 로테이션 (백테스트 검증)

> 학습·시뮬레이션 목적. 과거 성과는 미래 수익을 보장하지 않는다.

## 1. 진단 — 왜 계좌가 지고 있었나

레포의 실제 일봉(`state/price_history.json`, 30종목 × 592거래일, 2024-01 ~ 2026-06)으로
구간을 측정하면:

| 대상 | 총수익 |
|------|--------|
| **KOSPI 단순보유** | **+198%** |
| 대형주 30종목 동일가중 단순보유 | +300% |
| 상위 추세주(SK하이닉스·LS일렉트릭 등) | +500 ~ +1,500% |
| **현 가상 계좌(실현)** | **−1.3%** |

즉 이 구간은 **낙폭이 얕은 광범위 강세장**이었고, 계좌가 진 단 하나의 이유는
**그 강세장 내내 현금을 들고 있었던 것**이다. 원인 사슬:

1. 의사결정 routine 이 매번 `web_verify`(naver/yahoo)에 의존 → 세션 egress 정책이 403 차단.
2. `policy.price_data_quality.block_trade_if_confidence_below=medium` → 가격 신뢰도가 떨어지면 거래 차단.
3. 결과적으로 **데이터가 막힐 때마다 자동으로 "현금 보유"로 마비** → 강세장 상승을 통째로 놓침.
4. 가끔 들어간 소수 포지션은 거래비용(0.38%/회전)과 갭 손절로 마모.

## 2. 전략 — 검증된 규칙

`scripts/backtest_strategy.py` 가 그리드 탐색 + walk-forward(전반부 탐색 → 후반부 out-of-sample)로
도출·고정한 강건 설정:

- **유니버스**: 대형주 30종목.
- **신호 점수** = 0.5 × (60일 수익률) + 0.5 × (120일 수익률).
- **2중 필터**: 가격 > MA200(추세) **AND** 절대모멘텀 > 0 — 둘 다 통과한 종목만 후보.
- **보유**: 매수대상 점수 상위 **Top6 동일가중**(2026-06-30 Top10→Top6 축소 — 강한 추세주 집중, 후행주 충전재 배제). 매수대상 < 5개면 잔여는 현금
  (추세 없는 시장에 강제 배치하지 않음 — 무차별 buy&hold 가 아니다).
- **매수 게이트(2026-06-30 신설)**: 자격 통과분 중 ① **모멘텀 점수 ≥ 30**(저모멘텀 충전재 배제) AND
  ② **추적 대상(candidates ∪ 현재보유)** 만 매수. 30종목 가격풀에서 자유롭게 뽑던 것을 추적 종목으로 제한 —
  미추적 트렌드주는 `screen_universe.py` 의 승격 제안 → routine 이 thesis 와 함께 candidates 승격 후에만 매수
  대상이 된다(바스켓이 스스로 candidates 에 역등록하던 **순환 차단**). 게이트 파라미터(top_n·min_score·tracked_only)는
  `config/policy.json.momentum_strategy.config` 로 코드 수정 없이 튜닝.
- **리밸런스**: 약 1개월(21~42거래일). 저회전으로 거래비용·휩쏘 억제.
- **레짐필터 OFF**: 강세장에서 지수<MA200 현금화는 전 구간 수익을 깎았다 → 개별 추세필터로 대체.

## 3. 백테스트 결과 (`state/backtest_strategy.json`)

거래비용 매수 0.20% / 매도 0.38% 반영.

| 전략 | 총수익 | CAGR | Sharpe | MDD |
|------|--------|------|--------|-----|
| **★권장: Top10 월간리밸 항시투자** | **+313%** | +150% | **2.34** | −21% |
| KOSPI 단순보유(벤치) | +198% | +102% | 2.24 | −20% |
| Top5 월간리밸 항시투자 | +368% | +170% | 2.16 | −26% |
| Top5 주간리밸 + 레짐필터 ON | +92% | +52% | 1.16 | −25% |

**권장안은 수익·위험조정수익(Sharpe) 모두 벤치마크를 상회하고 낙폭은 동등**하다.
인근 파라미터(top_n 5~10, MA 100~200, 리밸 10~42)가 Sharpe 2.0~2.3에 군집 → 과최적화가 아니다.

### 정직한 한계
- Walk-forward OOS(2025-08~2026-06)에선 막판 멜트업 구간에서 KOSPI 집중보유(+145%)가
  분산 모멘텀(+96%)보다 강했다. 모멘텀의 엣지는 **약세·횡보 구간의 하방 회피**에서 주로 나온다.
- **어떤 항시투자 변형이든 −1.3% 와는 비교 불가** — 핵심 교정은 "현금 탈출"이다.

### 약세장 스트레스 검증 (`scripts/backtest_bear.py` → `state/backtest_bear.json`)
합성 강세장의 약세장 공백을, 실데이터 일간수익률에 **시장 드리프트만 음(-)으로 합성**해 검증
(상대강도·변동성 구조 보존). 결과(Top6·MA200·월간리밸, buy&hold 대비 %p):

| 시나리오 | 낙폭개선 | 초과수익 | 레짐필터 가치(ON−OFF) |
|---|---|---|---|
| 지속 약세 −40% | **+9.4** | **+27.4** | **+15.2** ✅ |
| 완만 약세 −20% | +6.5 | +14.7 | +2.7 ✅ |
| 중반 급락 −35%(30일) | **+21.1** | −1.7 | **−42.2** ❌ |
| 횡보+휩쏘 | +5.0 | −5.9 | −7.4 ❌ |
| 시계열 역전 | +3.9 | −3.2 | −15.8 ❌ |

**결론 2가지**
1. **하방 회피 엣지는 실재** — 모든 시나리오에서 추세필터(가격>MA200)가 buy&hold보다 낙폭을 줄였다
   (급락장 −43%→−22%). "모멘텀 = 약세장 자본보존" 주장이 정량 확인됨.
2. **지수-MA200 레짐 타이밍은 '공짜 개선'이 아니라 가혹한 트레이드오프** — 히스테리시스(enter/exit) 를
   그리드 탐색했으나 **어떤 설정도 강세장 비용 없이 약세장 방어를 주지 못했다**. 최선의 동적 레짐도 강세장
   수익을 **−150~−176%p**(예: +272%→+96~119%) 반납한다. 종목별 추세필터(가격>MA200)가 이미 강세장
   MDD 를 통제(−22)하므로, 지수 레짐은 약세장 방어 ↔ 강세장 수익의 맞교환일 뿐이다.
   → **결론: 기본값 OFF(항시투자) 유지가 합리적.** 동적 레짐은 `policy.momentum_strategy.regime_circuit_breaker`
   (기본 `enabled=false`)로 제공 — 거시 약세 증거가 누적될 때만 운영자가 수동 ON 하는 **서킷브레이커**.
   index-MA 자체가 휩쏘원이라, 향후 더 나은 대안은 **breadth(과반 종목이 MA200 상회) 기반 레짐**이다.

## 4. 실거래 연결

- `scripts/momentum_signal.py` → `state/momentum_signal.json` 에 **오늘 목표 바스켓 + 진입/이탈 변경분 + 종목별 점수**를 산출.
- `.github/workflows/fetch_history.yml` 가 가격 히스토리 갱신 후 백테스트·신호를 재생성·커밋 →
  네트워크가 막힌 웹 세션 routine 도 **커밋된 신호를 1순위 입력**으로 읽을 수 있다(stale 가격 추격 금지 불변).
- routine(09/18시)은 `momentum_signal.json` 의 목표 바스켓을 진입/회전 1차 후보로 삼되,
  기존 게이트(가격 신뢰도·heat·R/R·catalyst)는 그대로 통과시킨다.
